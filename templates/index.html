    Merge Account Manager Name

    A deal, task or coverage row can carry a name that doesn't match any registered user - e.g. typed with a short name ("Dimas") before that person's real full name ("Dimas Aradzna Himawan Nugroho") was ever set - which fragments one person's data under two different names everywhere. Merge the stray name into the correct one below. This doesn't rename any user account; it only relabels the data that already carries the stray name.

    Data Backup & Restore

    Download everything (opportunities, strategies, next actions with target dates, configuration and users) as one Excel file. The same file is the import template — use it to restore after a problem, or to move this dashboard to another cloud provider. Passwords are never exported; imported new users get the temporary password changeme123.

    |

    Sync from v1.9 (PythonAnywhere)

    While v1.9 (jphartogi.pythonanywhere.com) is still the live day-to-day system, pull its latest data into v2.0 directly over the web — no downloading or uploading a file. It's safe to run repeatedly: opportunities, tasks, users, login history, performance snapshots, account coverage and config are matched by id — a record already in v2.0 that doesn't exist in v1.9 (e.g. something added here directly) is left untouched, but a record that exists in both is overwritten with v1.9's version, since v1.9 remains the source of truth until the final cutover. Uses a login on v1.9 for an admin account there; the password is stored here but never shown back.

    Engine 1 Sync

    Push every opportunity here into Engine 1's PODS 2 (engine1.pythonanywhere.com) over its own API — creates new ones and updates ones already synced, so re-running it is always safe. Uses a login on Engine 1 for an account scoped to PODS 2 (or with rights over it); the password is stored here but never shown back.

    |

    If this server can't reach Engine 1 directly (common on a free PythonAnywhere plan), use Export for Engine 1 import instead — download the file here and upload it from a PODS-2-scoped account's Settings → Data Backup → Import on Engine 1. Tick "Replace all" there each time to avoid duplicates.
